# OIRO 配置指南（本机自助）

所有密钥、契约与 API 地址由用户在**本机**配置；不要写入 Git 仓库。`.gitignore` 已忽略 `.env`、`data/local/`、`install.state.json`、`model-keys.enc.json` 与用户契约目录。

## 1. 安装密钥（仅正式桌面包）

| 模式 | 变量 | 行为 |
|------|------|------|
| 开源/源码 | `OIRO_DISTRIBUTION=source`（默认） | 无需密钥 |
| 正式包 | `OIRO_DISTRIBUTION=packaged` | 首次需 `/install` 页或 `POST /api/install/activate` |

开发测试可设置 `OIRO_INSTALL_KEY_ACCEPT` 为固定测试密钥（勿用于正式发布）。

## 2. 模型网关密钥

路径：**系统设置 → 本机配置**，或 `PUT /api/local-config/model-keys`。

- 支持 DeepSeek、通义、OpenAI/Gemini/Grok（境外需先开启境外模型开关）、自建 OpenAI 兼容端点。
- 保存位置：`$OIRO_DATA_DIR/local/model-keys.enc.json`（Fernet 加密）。
- 界面与审计**不回显**完整密钥。

可选：仍可通过根目录 `.env` 注入密钥（开发用）；本机 UI 保存会覆盖进程环境并刷新网关。

## 3. OTA 渠道与官方契约

路径：**系统设置 → OTA 渠道**。

1. 填写本店 **OTA 账号/密码** 并保存连接。
2. 在 **官方契约 JSON 路径（本机）** 填写合作方提供的契约文件绝对路径，点击 **保存契约路径**。
3. 系统将校验 JSON、拒绝 `example: true` 与 `docs/official-contracts/` 下示例文件。
4. 契约路径与当前渠道账号绑定；未配置有效契约前保持沙盒/建议模式。
5. **自动执行与真实 OTA 写入默认关闭**；`live` 写入仍须契约已启用且写入开关允许（运维端或环境变量）。

示例契约仅作格式参考：`docs/official-contracts/*.example.json`。

## 4. PMS/CRS

路径：**系统设置 → PMS 集成**。

- **官方契约 JSON 路径**：本机文件，规则同 OTA。
- **官方 API 地址**：由厂商/你方运维提供的 HTTPS 基址（本仓库不编造生产 URL）。
- 账号密码可选；未启用正式契约时不会出站。

## 5. 数据目录

| 变量 | 含义 |
|------|------|
| `OIRO_DATA_DIR` | SQLite、LangGraph 检查点、本机密钥（默认 `项目/data`） |
| `DATABASE_URL` | 可改为 PostgreSQL（高级/多机；本地桌面默认 SQLite） |
| `OIRO_STATIC_ROOT` | 让 FastAPI 托管 `frontend/dist`（桌面一体启动） |

## 6. 环境变量速查（可选）

见根目录 `.env.example`。云托管相关变量仍可用于历史 Compose/K8s 部署，**本地桌面主线不依赖**远程 OIRO 服务器存放密钥。
