# OIRO 配置指南（酒店本机自助）

密钥、OTA/PMS 官方契约、API 地址均由酒店在**本机**填写；**不要**写入 Git。`.gitignore` 已忽略 `.env`、`data/local/`、`install.state.json`、`model-keys.enc.json` 与用户契约目录。

本指南假设你已按 [安装指南](安装指南.md) 在 Windows 上完成构建/安装，并**已激活安装密钥**（正式包）。**经营数据来自你在本机配置的连接**，不是仓库自带的演示种子长期当作生产数据源。

自动调价、真实 OTA **live 写入**与低风险自动执行均为**默认关闭**；下文说明如何在本机启用连接，而非默认打开写入。

---

## 1. 安装密钥（仅正式桌面包）

| 模式 | 含义 | 行为 |
|------|------|------|
| `OIRO_DISTRIBUTION=source` | 源码 / 开发 | **无需**密钥，门闩不拦截 API |
| `OIRO_DISTRIBUTION=packaged` | 绿色版 / 安装包 | 首次须在 **安装密钥** 页或 `POST /api/install/activate` 激活 |

**格式（必填校验）**：`OIRO-XXXX-XXXX-XXXX`  
即 `OIRO-` + **3 段** × 4 位 `A-Z` / `0-9`（例如 `OIRO-AB12-CD34-EF56`）。**错误示例**：`OIRO-TEST-0000-0000-0000`（四段，将被拒绝）。

状态文件：`%OIRO_DATA_DIR%\local\install.state.json`（桌面默认在用户数据目录）。

**开发测试**（仅本机调试门闩）：在后端进程中设置 `OIRO_INSTALL_KEY_ACCEPT` 为与激活页输入完全相同的密钥（须符合格式，如 `OIRO-TEST-0000-0000`）。**正式发给酒店的安装包不要依赖该变量。**

## 2. 模型网关密钥（本机）

**路径**：登录酒店账号 → **系统设置 → 本机配置**（或 API `PUT /api/local-config/model-keys`）。

- 支持 DeepSeek、通义、OpenAI / Gemini / Grok（境外需先开启境外开关）、自建 OpenAI 兼容端点。
- 保存位置：`$OIRO_DATA_DIR/local/model-keys.enc.json`（Fernet 加密）。
- 界面与审计**不**回显完整密钥。
- 中国区路由策略与出境限制见 `docs/04-模型网关规则.md`；**本仓库不新增境外默认路由**。

无密钥时相关能力降级为本地 Mock，流程可演示但**不能替代**你已配置的模型调用。

可选：开发时在项目根 `.env` 注入密钥；UI 保存会覆盖进程环境。

## 3. OTA 渠道与官方契约（酒店真实数据入口）

**路径**：**系统设置 → OTA 渠道**。

按顺序操作：

1. 填写 **本店 OTA 账号与密码**（酒店自有凭据），保存连接。
2. 在 **官方契约 JSON 路径（本机）** 填写合作方/运维交付的契约文件 **Windows 绝对路径**（如 `D:\oiro-config\ctrip.partner.json`），点击 **保存契约路径**。
3. 系统会校验 JSON 结构，并**拒绝**：
   - `example: true` 的示例；
   - 指向仓库内 `docs/official-contracts/` 下示例文件的路径。
4. 契约与当前保存的渠道账号绑定；更换账号需重新确认契约路径。
5. **无有效用户契约前**：调价与活动建议停留在建议/沙盒回执，**不会**伪装为已向生产 OTA 写入。
6. 真实 **live** 写入除契约外还须运维/环境写入开关允许（默认关闭）。

格式参考（勿直接用于生产）：`docs/official-contracts/*.example.json`。  
**本仓库不编造** OTA 生产域名；`base_url` 等信息以合作方契约为准。

## 4. PMS / CRS

**路径**：**系统设置 → PMS 集成**。

| 字段 | 说明 |
|------|------|
| 官方契约 JSON 路径 | 与 OTA 相同规则：本机绝对路径，禁用示例文件 |
| 官方 API 地址 | 厂商或贵司运维提供的 **HTTPS 基址**（自行填写，仓库无默认生产 URL） |
| 账号密码 | 可选；未启用正式契约时不会对外请求 |

PMS 数据与库存类能力依赖上述连接；未配置时相关面板为空态或模拟，**不应**当作已对接门店 PMS。

## 5. 数据目录与环境变量

| 变量 | 含义 |
|------|------|
| `OIRO_DATA_DIR` | SQLite、LangGraph 检查点、本机密钥（桌面包默认为用户目录下 `oiro/data`） |
| `DATABASE_URL` | 可选 PostgreSQL（多机/高级）；桌面默认 SQLite |
| `OIRO_STATIC_ROOT` | 由 Electron 注入为 `resources\renderer`；**勿**指向 asar 内路径 |
| `OIRO_DISTRIBUTION` | `packaged`（正式包）或 `source`（开发） |

完整变量表见根目录 `.env.example`（云部署历史项本地桌面通常不需要）。

## 6. Windows 打包相关（构建机）

构建者在酒店 IT 工作站上打包时：

```powershell
$env:CSC_IDENTITY_AUTO_DISCOVERY = "false"
$env:OIRO_DISTRIBUTION = "packaged"
.\desktop\scripts\build-windows.ps1
```

验收：

```powershell
Test-Path desktop\dist\win-unpacked\resources\renderer\index.html
Test-Path desktop\dist\win-unpacked\resources\backend\app\main.py
```

详见 [desktop/README.md](../desktop/README.md)。

## 7. 安全边界（配置层面）

- 酒店设置页**不展示**模型路由矩阵、原始 API 适配器密钥或境内外总开关（运维端职责）。
- 评价回复**不会**在未明确流程下自动对外发布。
- `pricing_strategy` / `review_reply` 任务在境外模型开启时仍不出境。
