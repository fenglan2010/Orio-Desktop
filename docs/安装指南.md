# OIRO 安装指南

本指南面向两条主线：**官方桌面安装包（Windows 优先）**与**开源从源码本地运行**。云上 Compose/K8s 为可选历史路径，见文末。

## 一、环境要求

| 组件 | 从源码运行 | 桌面正式包 |
|------|------------|------------|
| 操作系统 | Windows / macOS / Linux | Windows 10+（日常推荐） |
| Python | 3.11+ | 安装包内置或由 Electron 调用本机 venv |
| Node.js | 18+（仅构建前端） | 开发者构建时需要 |
| 数据库 | SQLite（默认，零配置） | 用户目录下 SQLite |

## 二、开源从源码运行（无需安装密钥）

```bash
git clone <your-repo-url> oiro
cd oiro
make dev
```

- 前端：http://127.0.0.1:5173  
- 后端：http://127.0.0.1:8000  
- 默认账号：`admin` / `admin123`  
- 环境变量 `OIRO_DISTRIBUTION` 默认为 `source`，**不启用**安装密钥门闩。

单进程桌面式（后端同时托管已构建前端）：

```bash
bash scripts/run-desktop-source.sh
# 构建 dist 后以 OIRO_STATIC_ROOT=frontend/dist 启动，浏览器打开 http://127.0.0.1:8000
```

## 三、官方桌面安装包

1. 在 **Windows** 上克隆仓库，在**项目根目录**创建 Python 虚拟环境并安装依赖：

```powershell
cd ORIO
python -m venv .venv
.\.venv\Scripts\pip install -r backend\requirements.txt
```

2. 构建前端并打包桌面壳（PowerShell，无需 bash / make）：

```powershell
cd frontend
npm ci
npm run build
cd ..\desktop
npm ci
$env:CSC_IDENTITY_AUTO_DISCOVERY = "false"
$env:OIRO_DISTRIBUTION = "packaged"
npm run pack:dir
```

或执行 `desktop\scripts\build-windows.ps1` 一步完成前端与 NSIS/目录产物。

3. 运行 `desktop\dist\win-unpacked\OIRO.exe`。安装包将后端放入 `resources\backend`、**已构建前端**放入 `resources\renderer`（`OIRO_STATIC_ROOT` 指向此目录）。`pack:dir` 在缺少 `frontend\dist\index.html` 时会立刻报错退出。

   **排障**：若 Electron 窗口空白，且浏览器打开 `http://127.0.0.1:8765/` 得到 `{"detail":"Not Found"}`，说明 uvicorn 已启动但未挂载静态页——请重新 `cd frontend; npm run build` 后再打包。

   Python 使用根目录 `.venv` 或本机 `python` / `py -3`。找不到 Python 时会弹出中文说明，而非进程崩溃。
4. 正式包设置 `OIRO_DISTRIBUTION=packaged`；安装或首次启动时输入 **应用安装密钥**（格式 `OIRO-XXXX-XXXX-XXXX`）。SQLite 位于用户数据目录 `oiro/data/`。

未签名构建请保持 `CSC_IDENTITY_AUTO_DISCOVERY=false`。若启用签名工具解压失败，可用管理员 PowerShell 或开启 Windows 开发人员模式。

> Linux/macOS 云构建环境**不产出**已签名 `.exe`；仓库提供 `desktop/` 脚手架与可复现 Windows 构建脚本。

## 四、开发调试桌面壳

```bash
# 终端 1
make dev

# 终端 2
cd desktop && npm install && OIRO_DEV_URL=http://127.0.0.1:5173 npm start
```

模拟正式包门闩：

```bash
export OIRO_DISTRIBUTION=packaged
export OIRO_INSTALL_KEY_ACCEPT=OIRO-TEST-0000-0000-0000
# 重启后端后访问前端，将跳转 /install 激活页
```
