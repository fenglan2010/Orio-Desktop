# OIRO 安装指南

本指南面向酒店 IT：**在 Windows 上获取、构建或安装本机 OIRO 桌面包**，完成安装密钥激活后，通过酒店自有的 OTA 契约、PMS/CRS API 与模型密钥接入**真实经营数据**。仓库：[fenglan2010/Orio-Desktop](https://github.com/fenglan2010/Orio-Desktop)。

演示账号与种子数据仅用于首次熟悉界面；**上线经营请以本机配置的官方连接为准**，不要长期依赖演示酒店数据充当真实 OTA/PMS 数据源。

自动调价与真实 OTA 自动执行**默认关闭**；本指南不改变该安全默认值。

---

## 酒店用户：正式安装包（无需安装 Python）

**一条龙**：**安装** → **打开 OIRO** → **输入安装密钥** → **登录** → 在系统设置中配置模型密钥与 OTA/PMS（见 [配置指南](配置指南.md)）。

1. 运行 `OIRO-Setup-*.exe`（或 IT 提供的绿色版 `OIRO.exe`）。未签名包可能有 SmartScreen 提示。
2. 从开始菜单打开 **OIRO**。应用内置 `resources\python` 后端，**不依赖**本机 conda、`py` 启动器或源码目录旁的 `.venv`。
3. 在激活页输入安装密钥，格式 **`OIRO-XXXX-XXXX-XXXX`**（开发/内测示例：`OIRO-TEST-0000-0000`）。
4. 进入登录页后使用酒店账号登录；经营数据来自后续配置的 **OTA 官方契约路径** 与 **PMS API**，不是长期依赖演示店数据。

若窗口空白：请升级到包含 **`resources\python\python.exe`** 的最新安装包；旧包会因 PATH 中无 Python 而无法启动后端。

| 角色 | 组件 | 要求 |
|------|------|------|
| **酒店用户** | 操作系统 | Windows 10/11（64 位） |

```powershell
git clone https://github.com/fenglan2010/Orio-Desktop.git Orio-Desktop
cd Orio-Desktop
```

## 三、在 Windows 上构建桌面包（IT / 开发者）

一键脚本会：**构建前端** → **下载并嵌入 Python 3.11 + 后端依赖** → **打包**。产物含 `resources\python\python.exe`。

```powershell
.\desktop\scripts\build-windows.ps1
```

生成绿色版：`desktop\dist\win-unpacked\OIRO.exe`。

可选 **未签名 NSIS 安装包**（CI 与本地相同环境变量，**不**配置代码签名证书）：

```powershell
.\desktop\scripts\build-windows.ps1 -WithInstaller
```

产物：`desktop\dist\OIRO-Setup-0.1.0.exe`（版本号以 `desktop\package.json` 为准）。

构建前请确认：

```powershell
$env:CSC_IDENTITY_AUTO_DISCOVERY = "false"
$env:OIRO_DISTRIBUTION = "packaged"
```

`CSC_IDENTITY_AUTO_DISCOVERY=false` 可避免 electron-builder 拉取 `winCodeSign` 后在无符号链接权限时失败。若你自行启用签名且遇符号链接错误，用**管理员 PowerShell** 或开启 **开发人员模式**。

### 3.3 打包后必做验收（PowerShell）

```powershell
$root = "desktop\dist\win-unpacked"
Test-Path (Join-Path $root "resources\renderer\index.html")   # 应为 True
Test-Path (Join-Path $root "resources\backend\app\main.py")   # 应为 True
Test-Path (Join-Path $root "resources\python\python.exe")    # 应为 True
```

前端必须在 **`resources\renderer`**（`extraResources`），与 **`resources\backend`** 同级。Python **无法**从 `app.asar` 读取静态文件；若只打进 asar，典型现象：

- Electron **窗口空白**；
- 浏览器访问 `http://127.0.0.1:8765/` 返回 `{"detail":"Not Found"}`（API 已起但未挂载页面）。

处理：重新执行 `.\desktop\scripts\build-windows.ps1`（脚本会先 `npm run build` 前端）。若跳过构建直接 `npm run pack:dir` 且缺少 `frontend\dist\index.html`，打包脚本会**立即报错退出**。

### 3.4 手动分步（与脚本等价）

```powershell
cd frontend
npm ci
npm run build
cd ..\desktop
npm ci
$env:CSC_IDENTITY_AUTO_DISCOVERY = "false"
$env:OIRO_DISTRIBUTION = "packaged"
npm run pack:dir          # 会自动构建缺失的前端
# 或 npm run pack:win:nsis   # 仅 NSIS 安装包
```

### 3.5 未签名安装包与 SmartScreen

本仓库 CI 与文档路径均为**无代码签名**构建。首次运行 `OIRO-Setup-*.exe` 或 `OIRO.exe` 时，Windows 可能显示 **SmartScreen / 未知发布者**。这属于未签名应用的正常提示；是否继续由酒店安全策略决定。本仓库不提供也不伪造签名证书。

## 四、首次启动与安装密钥

1. 运行 `desktop\dist\win-unpacked\OIRO.exe`（或安装后的开始菜单快捷方式）。
2. 正式包环境为 `OIRO_DISTRIBUTION=packaged`；若尚未激活，应用会打开 **安装密钥** 页。
3. 输入商务提供的密钥，格式 **`OIRO-XXXX-XXXX-XXXX`**。
4. 激活后进入 **开通本店**：填写酒店名称与城市等档案、创建首个管理员账号，并至少添加一个真实房型（代码、名称、数量、基础价、位置）。完成后进入工作台；也可稍后在系统设置中修改。
5. 使用刚创建的管理员账号登录。SQLite 与用户本机配置位于用户数据目录下的 `oiro/data/`（参见 [配置指南](配置指南.md)）。正式安装包**不会**默认提供 `admin` / `admin123` 或演示酒店数据。

**源码/开发模式**（`OIRO_DISTRIBUTION=source`，默认）：**不需要**安装密钥，适合贡献者与内网试运行。

仅 **本地开发** 模拟门闩时，可设置环境变量 `OIRO_INSTALL_KEY_ACCEPT` 为与界面输入一致的测试密钥（须符合上述三段格式，例如 `OIRO-TEST-0000-0000`）。**勿将测试密钥用于对外分发的正式包。**

## 五、开通后：接入酒店真实数据（概要）

详细步骤见 [配置指南](配置指南.md) 与 [操作运行指南](操作运行指南.md)。

| 步骤 | 位置 | 说明 |
|------|------|------|
| 模型 API Key | 系统设置 → 本机配置 | DeepSeek / 通义等，**仅存本机**加密文件 |
| OTA | 系统设置 → OTA 渠道 | 保存**本店账号** + **官方契约 JSON 的本地绝对路径**（非仓库内 `example` 文件） |
| PMS/CRS | 系统设置 → PMS 集成 | 契约路径 + 厂商提供的 **HTTPS API 基址** |
| 数据含义 | L1–L5 | 接入成功后指标与写入以**酒店连接**为准；无有效契约时保持建议/沙盒，**不**用演示数据冒充生产 |

运维工作台（`#/ops/login`）仍可用于批量与写入开关；酒店侧日常以本机设置为主。


- 后端：http://127.0.0.1:8000  
- 默认演示账号：`admin` / `admin123`（**演示**数据，非真实 OTA）
