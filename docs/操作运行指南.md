# OIRO 操作运行指南

## 日常启动

### 从源码（推荐贡献者与酒店内网试运行）

```bash
make dev
```

浏览器打开 http://127.0.0.1:5173 ，使用酒店账号登录。

### 桌面正式包

从开始菜单启动 **OIRO**。若提示安装密钥，在激活页输入密钥后进入登录页。

### 内置前端 + API 一体

```bash
bash scripts/run-desktop-source.sh
```

访问 http://127.0.0.1:8000 。

## 登录与角色

- 酒店端默认演示：`admin` / `admin123`
- 运维工作台：`#/ops/login`（种子账号见 `README.md`）
- 运维端布局与菜单**保持既有设计**；本地模式下契约也可在酒店设置中配置，运维端仍可用于批量与写入开关。

## 典型工作流

1. **本机配置**：在设置中填写 DeepSeek/通义等 API Key。
2. **连接 OTA**：保存账号密码与契约 JSON 路径。
3. **（可选）PMS**：保存 API 地址与契约路径。
4. **监控与诊断**：L1 大屏 → L2 分析 → 生成策略。
5. **人审与执行**：L3 执行中心；默认人审，低风险自动执行默认**关闭**。
6. **审计**：L5 / 日志查看；不含密钥明文。

## 写入与安全边界

- 无有效用户提供的官方契约：**仅沙盒回执与建议**，不伪造生产写入。
- 评价回复**不会**自动对外发布。
- `pricing_strategy` / `review_reply` 在境外模型开启时仍不出境。

## 停止与重置

- 停止：终端 `Ctrl+C`；桌面包关闭窗口会结束 API 子进程。
- 重置演示数据：`make reset`（清空 SQLite 演示数据，**不删除**本机 `model-keys.enc.json` 与 `install.state.json`，除非你手动删除 `data/local/`）。

## 故障排查

| 现象 | 检查 |
|------|------|
| 正式包无法登录 | `/api/install/status` 是否 `blocked`；是否已激活 |
| 模型无响应 | 设置 → 本机配置是否已保存 Key；无 Key 时走 Mock |
| 契约未启用 | 路径是否存在、是否为示例 JSON、platform 是否与渠道一致 |
| 桌面白屏 | 是否已 `npm run build`；`OIRO_STATIC_ROOT` 是否指向 `frontend/dist` |

## 运行测试

```bash
make test
```

验证安装门闩、契约绑定、PMS 地址与本机密钥落盘。
